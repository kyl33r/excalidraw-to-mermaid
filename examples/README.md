# Example Excalidraw documents

These fixtures are valid Excalidraw JSON documents intended for manual inspection and future Excalidraw-to-Mermaid conversion tests.

- `01-basic-flow.excalidraw` — a four-step linear flow with rectangle, diamond, and ellipse nodes.
- `02-branching-flow.excalidraw` — a decision that branches into shipping or backorder paths before rejoining.
- `03-grouped-process.excalidraw` — a framed process with grouped elements and bound text.
- `04-quant-agent.excalidraw` — an imported quantitative-agent architecture generated by Mermaid-to-Excalidraw, with 23 rectangle node candidates and 83 source elements.

Open any file in Excalidraw using **Open** or by dragging the file onto the canvas.

## Inspect with the current Phase 1–3 pipeline

From the repository root:

```bash
npm run build
INPUT=./examples/01-basic-flow.excalidraw node --input-type=module <<'NODE'
import fs from "node:fs";
import {
  parseExcalidrawJson,
  normalizeExcalidrawElements,
  extractGraphNodes,
} from "./dist/index.js";

const parsed = parseExcalidrawJson(fs.readFileSync(process.env.INPUT, "utf8"));
const normalized = normalizeExcalidrawElements(parsed.elements);
const extracted = extractGraphNodes(normalized.elements);
console.log(JSON.stringify({
  nodes: extracted.nodes,
  warnings: [...normalized.warnings, ...extracted.warnings],
}, null, 2));
NODE
```

At the current phase boundary, shape nodes are extracted but their contained labels and arrows are not yet resolved into graph labels and edges. Those parts of these fixtures are intentionally present for later phases.
